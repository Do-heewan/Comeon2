# 모여모여 🌷

**섞이는 순간, 우리가 되는 시간.**

이름을 넣고 팀 수를 고르면, 우리 반 친구들을 고르게 나누어 주는 랜덤 팀 만들기 웹앱입니다.
파스텔 색감의 작은 뽑기 기계에서 이름 공이 섞이고, 새로운 팀원이 한 명씩 공개됩니다.
수업 시간의 모둠 활동부터 동아리, 워크숍까지 가볍게 활용하세요.

![모여모여의 이름 입력과 셔플 화면](docs/images/desktop-initial.png)

## 설치 없이 바로 사용하기

1. 저장소의 **[모여모여.html](./모여모여.html)** 파일을 엽니다.
2. GitHub 파일 화면 오른쪽 위의 **Download raw file** 버튼으로 다운로드합니다.
3. 내려받은 파일을 **더블클릭**하면 브라우저에서 바로 실행됩니다.

인터넷 연결이나 프로그램 설치가 필요하지 않습니다. 파일 하나를 USB에 담아 교실 PC로 옮겨도 사용할 수 있습니다.
GitHub의 파일 미리보기 화면에서는 앱이 실행되지 않으므로, 꼭 다운로드한 뒤 열어 주세요.

## 이런 기능이 있어요

| 기능 | 설명 |
| --- | --- |
| 🎲 랜덤 팀 배분 | 2–200명을 원하는 팀 수로 배정하고, 팀별 인원 차이를 최대 1명으로 유지합니다. |
| 🫧 눈에 보이는 셔플 | 이름 공이 뽑기 기계 안에서 섞인 뒤 팀원이 한 명씩 공개됩니다. |
| ⏱️ 진행 속도 선택 | 여유로운 8초 또는 빠른 3초 셔플, 결과 바로 보기, 취소를 지원합니다. |
| 🌷 귀여운 팀 카드 | 튤립·클로버·별빛 등 파스텔 테마를 제공하고 팀 이름을 직접 바꿀 수 있습니다. |
| 📋 결과 활용 | 결과 복사, 한글 텍스트 파일 저장, 다시 섞기를 지원합니다. |
| 🔊 수업에 맞춘 화면 | 선택형 효과음과 전체 화면을 제공하며, PC와 모바일 화면에 맞게 배치됩니다. |
| ♡ 편안한 사용 | 기기의 동작 줄이기 설정을 반영하며, 효과음은 기본적으로 꺼져 있습니다. |

## 수업에서 사용하기

1. **이름 입력** — 한 줄에 한 명씩 입력하거나 명단을 붙여 넣습니다. 쉼표·세미콜론·탭으로 구분한 목록도 가능합니다.
2. **팀 수 선택** — 2팀부터 참여 인원 수까지 선택할 수 있습니다. 팀당 예상 인원을 화면에서 확인하세요.
3. **팀 만들기** — 셔플 속도를 고르고 **두근두근, 팀 만들기**를 누릅니다.
4. **결과 확인** — 팀 이름을 바꾸고 결과를 복사하거나 저장하세요. **다시 섞기**로 새로운 조합을 뽑을 수 있습니다.

> 먼저 둘러보고 싶다면 **예시 넣기**를 눌러 보세요. 24명의 예시 친구와 4개 팀이 준비됩니다.
> 동명이인은 각각 다른 참가자로 처리됩니다. `김민지 1`, `김민지 2`처럼 입력하면 구분하기 쉽습니다.

## 개발 환경에서 실행하기

[Node.js](https://nodejs.org/) **18 이상**이 필요합니다. 외부 패키지가 없어 `npm install` 없이 실행할 수 있습니다.

```sh
git clone https://github.com/Do-heewan/Comeon2.git
cd Comeon2
npm start
```

브라우저에서 **[http://localhost:3000](http://localhost:3000)**을 여세요.
Windows에서는 `start.bat`을 더블클릭해도 됩니다. 서버 종료는 터미널에서 `Ctrl+C`를 누르세요.

포트를 바꾸려면 PowerShell에서 다음과 같이 실행합니다.

```powershell
$env:PORT=3001
npm start
```

## 테스트와 빌드

```sh
npm test
npm run build
```

- **테스트:** Node.js 기본 테스트 러너로 10개 테스트를 실행합니다. 이름 파싱, 동명이인 보존, 난수 처리, 인원 균등 배분, 잘못된 입력을 검증합니다.
- **빌드:** `모여모여.html` 단독 실행 파일을 갱신하고, `dist/`에 정적 사이트 파일을 생성합니다.
- **배포:** `dist/`를 GitHub Pages 등 정적 사이트 호스팅에 올릴 수 있습니다. 별도 백엔드나 데이터베이스가 필요하지 않습니다.

## 배분 방식과 개인정보

참가자 목록을 Fisher–Yates 알고리즘으로 섞은 다음, 모든 참가자를 한 번씩 배정합니다.
브라우저의 `crypto.getRandomValues`를 우선 사용하며, 지원하지 않는 환경에서는 `Math.random`으로 동작합니다.
나누어떨어지지 않는 경우 앞쪽 팀에 한 명씩 더 배정합니다. 예를 들어 **25명을 4팀으로 나누면 7·6·6·6명**이 됩니다.

입력한 이름과 결과는 **현재 브라우저의 메모리에서만 처리**하며, 서버로 보내거나 브라우저 저장소에 기록하지 않습니다.
새로고침하면 초기화되므로 필요한 결과는 복사하거나 파일로 저장해 주세요.
계정, 외부 API, 분석 도구, CDN 없이 작동하며, 로컬 개발 서버는 `127.0.0.1`에서만 실행됩니다.

```text
├── index.html          # 화면 구성
├── styles.css          # 파스텔 디자인과 반응형 스타일
├── app.js              # 셔플 애니메이션과 화면 상호작용
├── team-utils.js       # 이름 파싱과 랜덤 팀 배분
├── server.mjs          # 로컬 개발 서버
├── build.mjs           # 정적 사이트·단독 HTML 빌드
├── tests/              # 팀 배분 로직 테스트
├── docs/images/        # README 화면 예시
├── dist/               # 빌드한 정적 사이트
└── 모여모여.html        # 설치 없이 여는 단독 실행 파일
```
